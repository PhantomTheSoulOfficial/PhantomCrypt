# PhantomCrypt 🔐

**PhantomCrypt** is a cross-platform image processing and cryptography
application developed in C++ and Qt.

The project is being developed as part of a graduation project in
Information Security, with the goal of becoming a complete,
user-friendly tool suitable for everyday use.

## About

PhantomCrypt is a desktop application designed to provide users with
tools for working with images and applying cryptographic transformations.

The project focuses on creating a reliable, understandable and
accessible application rather than a demonstration or research
prototype.

The current development stage is focused on designing the architecture,
evaluating implementation approaches and building the core functionality.

## Project Status

🚧 **In Development**

PhantomCrypt is currently under active development.

The architecture and implementation approaches are being established
before moving towards the complete user-facing application.

## Goals

- Provide a complete desktop application for end users
- Implement image processing and cryptographic functionality
- Maintain a clear and modular software architecture
- Support cross-platform development
- Provide a convenient graphical user interface
- Make the application understandable and accessible to users

# PhantomCrypt 🔐

**PhantomCrypt** — кроссплатформенное приложение для работы с
изображениями и криптографическими преобразованиями, разрабатываемое
на C++ и Qt.

Проект создаётся в рамках дипломной работы по специальности
«Обеспечение информационной безопасности автоматизированных систем»,
при этом конечной целью является полноценный и удобный инструмент,
которым смогут пользоваться обычные пользователи.

## О проекте

PhantomCrypt — настольное приложение, предназначенное для работы
с изображениями и применения криптографических преобразований.

Основная цель проекта — создание полноценного, надёжного и понятного
пользовательского инструмента, а не демонстрационного или
исследовательского прототипа.

На текущем этапе ведётся разработка архитектуры, выбор подходов
к реализации и создание базовой функциональности.

## Статус проекта

🚧 **В разработке**

PhantomCrypt находится на активной стадии разработки.

В настоящее время формируется архитектура приложения и определяются
основные подходы к реализации его компонентов.

## Технологии
